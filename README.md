# 🎬 Pesquisa Culturama

> Um projeto prático focado na construção de formulários web eficientes, otimização para motores de busca (SEO) e práticas de acessibilidade.

## 💻 Sobre o Projeto

O **Pesquisa Culturama** é uma página web desenvolvida para aplicar conceitos avançados de estruturação de **HTML5** e estilização **CSS3**. O objetivo principal não foi apenas criar uma página visualmente agradável, mas sim uma página **funcional, encontrável e acessível**.

Este projeto simula um formulário de pesquisa de opinião, onde o usuário pode interagir com diferentes tipos de campos de entrada.

---

## 🧠 Aprendizados e Destaques

Neste projeto, foquei em três pilares fundamentais do desenvolvimento Front-end moderno:

### 1. 📝 Formulários Complexos
* Uso correto das tags `<form>`, `<input>`, `<label>`, `<select>` e `<textarea>`.
* Implementação de diferentes tipos de *inputs* (text, email, radio buttons, checkboxes).
* Validações nativas do HTML (required, type validation).

### 2. 🔍 SEO (Search Engine Optimization)
* Estruturação semântica do código para facilitar a leitura por robôs de busca.
* Uso estratégico de **Meta Tags** no `<head>` para melhorar a indexação.
* Hierarquia correta de títulos (`h1`, `h2`, `h3`).

### 3. ♿ Acessibilidade (a11y)
* Uso de atributos `aria-label` e `role` quando necessário.
* Associação correta entre `label` e `input` (essencial para leitores de tela).
* Contraste de cores adequado e foco visível para navegação via teclado.
